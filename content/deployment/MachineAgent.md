# AppDynamics Java Agent Deployment

## Overview
This document explains how to deploy AppDynamics Java Agent on Linux.

## Prerequisites
- Java 11+
- Linux access
- Controller URL and credentials

## Step-by-Step
1. Download agent from AppDynamics portal
2. Extract agent files
3. Configure controller-info.xml
4. Restart application

## Common Issues
- Agent not reporting → Check connectivity
- JVM crash → Verify compatibility

## Best Practices
- Always use latest agent
- Enable SSL
